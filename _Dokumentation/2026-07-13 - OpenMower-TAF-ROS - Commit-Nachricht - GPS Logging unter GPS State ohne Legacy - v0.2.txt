BL_Remove legacy GPS logging compatibility
Date: 2026-07-13

Summary:
- Made gps_state/settings/* and gps_state/logging/* the only app-facing GPS logging API.
- Removed the former settings/mower_logic/satellite_logging MQTT subscriptions, publications, and fallback behavior.
- Removed the satellite_logging_enabled dynamic setting and all runtime behavior tied to it.
- Removed request_origin, legacy_setting_enabled, and duplicated top-level runtime fields from the public status payload.
- Bumped the GPS logging status and last-session schemas to v2.
- Updated the API and app integration documentation for a coordinated backend/app deployment without legacy compatibility.
- Removed obsolete v0.1 GPS logging delivery documents that described the transitional compatibility layer.
